# 漫畫來源白畫面修正版 0.9.9+131

舊套件或匯入的來源資料，可能沒有最近使用、釘選、圖示或語言欄位。來源列表原本直接使用空值，導致整個列表顯示灰白色錯誤畫面。

本版讓最近使用、釘選與來源顯示安全處理空值，並在匯入舊 JSON 時補齊缺少的預設值。來源 ID、來源程式、已儲存偏好與明確的啟用／停用設定保留，不需重新匯入書庫。更新後可以重新啟用先前停用的漫畫來源。

保留 130 版的書庫效能與背景同步、繁體中文、小說正文插圖。Windows 與 Android 使用相同的共用修正；Android 延用相同簽章，可直接更新先前版本。

新增測試覆蓋舊 JSON、資料庫空欄位、漫畫／動畫／小說來源列表、空來源頁及釘選操作。

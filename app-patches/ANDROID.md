# Mangayomi 插圖版 Android 安裝說明

這是基於 Mangayomi 0.9.9 的非官方繁體中文插圖版，版本號 0.9.9+129，保留小說正文插圖功能，並新增完整的「繁體中文（台灣）」介面。

## 安裝與使用

1. 將 `Mangayomi-0.9.9-zh-TW-android.apk` 傳到手機或平板並安裝。這是通用 APK，安裝時會自動使用對應架構；最低 Android 7.0（API 24）。已安裝插圖版 128 時可直接更新，沿用同一組簽章、套件 ID 及資料。
2. App 名稱為「Mangayomi 插圖版」，可以與原版並存，不必解除安裝原版。
   首次啟動若開啟 Android 的「管理所有檔案」權限頁，請允許後返回 App。
3. 若要帶入既有書庫，可先在原版匯出備份，再於插圖版還原；也可以設定原本的同步伺服器。兩個 App 的內部資料各自獨立。
4. 在小說來源儲存庫加入 `https://raw.githubusercontent.com/thomaslou0202/Mangayomi-Plugins/main/novel_index.json`，安裝／更新「輕小說文庫」至 0.3.6。
5. 開啟插圖章節即可在正文內查看圖片。0.3.6 已移除開頭的 WebView 查看連結；已下載的舊章節需重新下載才會移除舊連結。
6. 沒有既存語言偏好時會預設使用繁體中文。若沿用的設定仍是簡體或英文，到「更多 → 設定 → 外觀 → 介面語言」選「繁體中文（台灣）」。英文介面路徑為 More → Settings → Appearance → App language。

本版支援連續捲動、單頁與雙頁；翻頁模式讓每張插圖各佔一頁並縮放至頁面內。未新增完整插圖離線下載功能，主要供線上閱讀。

## 簽章與更新

應用程式 ID：`com.kodjodevf.mangayomi.illustrations`。本版使用自己的固定發行簽章，之後相同簽章的插圖版 APK 可以直接更新。本版不能覆蓋官方簽章的 App，也不是 Google Play 發行版本。

簽章私鑰與以 Windows 使用者帳號保護的密碼存在這台電腦的 `D:\Mangayomi\signing`，並透過 GitHub Actions 加密 Secrets 提供給建置流程；不包含在原始碼及安裝包中。後續發行更新應沿用這組簽章。

## 驗證範圍

建置流程會執行共用閱讀器的 19 項測試、編譯通用正式版 APK、檢查 APK 簽章與套件資訊，並在 Android 15 模擬器確認安裝、啟動及平板尺寸切換。模擬器不含使用者的帳號與書庫；實際網站登入與手機／平板章節閱讀仍需裝置試用。

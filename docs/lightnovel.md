# 輕之國度 0.1.0

在 Mangayomi「瀏覽 → 小說擴充套件」重新整理，安裝「輕之國度」。已加入本套件庫的裝置不必新增網址，也不需要更新 App。適用 Windows 與 Android，目前正式版 +142 可使用。

## 功能

- 熱門、最近更新與搜尋分頁；可直接搜尋繁體或簡體關鍵字。
- 使用網站正在使用的公開 PC 介面，逐頁讀取所有分卷與章節，不只解析作品頁預設顯示的少數章節。
- 固定章節編號、分卷標示、完整正文及插圖，保留圖片的站方簽名網址。
- 預設將書名、章名與正文轉為繁體中文；可在來源設定的「顯示文字」切換成網站原文。
- 章節沿用網站提供的順序；不將同名作品的其他版本合併進來。
- 正文與下載使用同一個來源介面，可搭配 App 的小說下載功能。插圖保留線上網址，這個來源本身不會將圖片打包為離線檔。

## 使用已登入帳號

1. 在來源的內建網頁開啟 [輕之國度](https://www.lightnovel.fun/tw)，由自己完成登入。
2. 到來源設定，將「閱讀帳號」切換成「使用內建網頁已登入帳號」。
3. 回到作品頁重新整理目錄，再開啟章節。

預設為訪客模式。切換帳號模式後，來源會在相同網站的內建網頁環境中，以網站自己的登入資訊呼叫閱讀介面；不要求在套件設定輸入密碼，不將登入授權回傳給套件，也不會替你購買或解鎖章節。帳號過期時請重新在內建網頁登入。

勇者、付費或其他限定章節仍依站方回傳的帳號權限判斷。未取得權限的章節會保留標示並說明原因，預覽不會被誤存為完整章節。登入共享流程已以模擬帳號狀態測試；真實帳號權限仍需由使用者裝置確認。

## 驗證

- 公開熱門與最近更新清單各 20 筆。
- 搜尋「無職」第一頁 20 筆、第二頁 2 筆，能找到《無職轉生》。最近更新及搜尋介面使用從 0 開始的頁碼，熱門與目錄使用從 1 開始的頁碼。
- 《零之使魔》（作品 31160）全部 2 個分卷、61 章，含第一分卷超過 50 章的第二頁。
- 作品 31160 的公開章節 314194：542 個段落，轉換前後順序一致。
- 《無職轉生》（作品 168）的公開章節 313737：4,570 個段落及 20 張圖片，圖片網址保留不變，抽查兩張回傳 JPEG。
- 單元測試涵蓋分頁、完整目錄、排序、繁體轉換、圖片簽名、安全網址、受限章節、帳號狀態、驗證與暫時連線失敗。

完整小說文字與圖片未放入套件庫；測試使用人工編寫的短內容。

# 輕之國度 0.1.2

在 Mangayomi「瀏覽 → 小說擴充套件」重新整理，安裝「輕之國度」。已加入本套件庫的裝置不必新增網址，也不需要更新 App。適用 Windows 與 Android，目前正式版 +142 可使用。

## 功能

- 熱門、最近更新與搜尋分頁；可直接搜尋繁體或簡體關鍵字。
- 使用網站正在使用的公開 PC 介面，逐頁讀取所有分卷與章節，不只解析作品頁預設顯示的少數章節。
- 固定章節編號、分卷標示、完整正文及插圖，保留圖片的站方簽名網址。
- 預設將書名、章名與正文轉為繁體中文；可在來源設定的「顯示文字」切換成網站原文。
- 章節沿用網站提供的順序；不將同名作品的其他版本合併進來。
- 正文與下載使用同一個來源介面，可搭配 App 的小說下載功能。插圖保留線上網址，這個來源本身不會將圖片打包為離線檔。

## 一般閱讀與需要帳號的章節

一般瀏覽、搜尋、目錄與公開章節一律先使用訪客模式，不需要登入，也不需要切換帳號設定。

只有站方明確將章節標示為受限時，來源才嘗試使用內建網頁的既有登入狀態：

1. 如果已登入且具備該章節的閱讀權限，會自動繼續讀取正文。
2. 如果尚未登入，才顯示「此章節需要帳號」的提示；請在來源的內建網頁開啟 [輕之國度](https://www.lightnovel.fun/tw)，由自己完成登入，再回來重試該章節。
3. 如果已登入但仍未取得勇者資格或付費權限，會說明帳號權限不足；登入不等同取得所有章節權限。

0.1.0 的「閱讀帳號」選項已移除，舊設定也不再影響一般章節。網站的人機驗證仍與帳號登入分開處理。

登入資訊留在內建網頁環境，來源不要求輸入密碼，也不將登入授權回傳給套件，不會替你購買或解鎖章節。預覽不會被誤存為完整正文。登入共享流程已以模擬帳號狀態測試；真實帳號權限仍需由使用者裝置確認。

## 0.1.2 一般瀏覽修正

修正套件先將 POST 資料轉成 JSON 字串、App 的 `JsHttpClient._toHttpResponse` 再次 JSON 編碼，導致站方只收到字串而缺少分頁欄位的問題。套件現在傳入物件，交由 App 進行一次 JSON 編碼；內建網頁的 fetch 仍按瀏覽器介面使用 JSON 字串。

在正式 Windows +142 的內建網頁環境重現舊格式：站方回傳代碼 3、分頁參數錯誤；改成正確格式後，同一個介面回傳代碼 0 與 20 筆書籍。一般請求的錯誤也不再誤導為必須登入。

測試環境已改成符合 App 的 JSON 傳送規則，另增加傳送物件的回歸測試。本次只需更新來源，不需更新 App。

## 驗證

- 公開熱門與最近更新清單各 20 筆。
- 搜尋「無職」第一頁 20 筆、第二頁 2 筆，能找到《無職轉生》。最近更新及搜尋介面使用從 0 開始的頁碼，熱門與目錄使用從 1 開始的頁碼。
- 《零之使魔》（作品 31160）全部 2 個分卷、61 章，含第一分卷超過 50 章的第二頁。
- 作品 31160 的公開章節 314194：542 個段落，轉換前後順序一致。
- 《無職轉生》（作品 168）的公開章節 313737：4,570 個段落及 20 張圖片，圖片網址保留不變，抽查兩張回傳 JPEG。
- 0.1.1 已重新實測《無職轉生》的公開章節，不使用內建網頁帳號即可讀取正文及 20 張插圖。
- 單元測試涵蓋分頁、完整目錄、排序、繁體轉換、圖片簽名、安全網址、受限章節、帳號狀態、驗證與暫時連線失敗。

完整小說文字與圖片未放入套件庫；測試使用人工編寫的短內容。

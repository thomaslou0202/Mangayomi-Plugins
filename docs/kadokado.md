# KadoKado 角角者

版本 **0.1.1**，固定 ID `1827634462`，類型為「小說」。網址使用 [www.kadokado.cn](https://www.kadokado.cn/)，資料來自網站自己的 API（`api.kadokado.cn`），作品名稱、目錄與正文都是台灣角川原本的繁體字，不經過簡體轉換。

## 功能

- **熱門**：預設「本週人氣」排行（最多 100 部）；可在來源設定改成本月／今日人氣或本週／本月收藏。
- **最新**：最近更新的 50 部作品。
- **搜尋**：網站的相關度排序，每頁 20 筆；也可直接貼上作品網址。
- **目錄**：依網站分卷，章名前加上全書連續編號，讓 App 的下一章與排序正確。**只列出免費章節**，付費或讀角券章節不顯示。
- **正文**：段落、強調與網站圖床的插圖；其他內容（腳本、外部圖片、內嵌框架）一律移除。

## 0.1.1：圖片

網站把封面與正文插圖存成路徑（或 Cloud Storage 網址），再透過 `img.kadokado.com.tw` 的圖片代理顯示。0.1.0 只接受完整網址，正文插圖因此讀不出來；0.1.1 依網站相同規則轉成代理網址，並支援延遲載入的 `data-src`。

## 登入

網站只對登入的會員顯示章節正文，未登入時 API 回傳空白內容。

1. 在 Mangayomi「瀏覽 → 小說來源」長按或進入 KadoKado，開啟來源的內建網頁（WebView）。
2. 在 `www.kadokado.cn` 登入你的 KadoKado 帳號。
3. 回到作品重新開啟章節。

套件不保存帳號密碼，讀取正文時沿用內建網頁的登入狀態。未登入會顯示 `KK-LOGIN`。

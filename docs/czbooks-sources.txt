The public frontend's search handler links to /s/<UTF-8 keyword>; pagination
adds /<page>. Curated rankings expose day/week/total, not latest updates.
The source deliberately hides the latest tab instead of relabelling a daily
ranking as latest. Categories and their route names come from the site menu.

The source parses .novel-list .novel-item, .novel-detail, .chapter-list li and
.chapter-detail .content. Public chapterNumber hints are sorted when complete
and unique; query hints are stripped from canonical chapter URL identity.

Original chapter/volume digits are displayed fullwidth, preventing embedded
Ch./Ep./season numbers from overriding the positive global ASCII sequence.
That leading sequence supplies a unique ingestion identity and independent
reader sort key, while equal padding preserves name sorting.

Direct HTTP returned a Cloudflare challenge. The plugin uses the running
app's ordinary WebView page-rendering helper. It does not extract cookies,
solve verification challenges, submit login forms or use third-party proxies.
The source is original code; website scripts, novels and images are not bundled.
Only aggregate statistics and content hashes are retained in the package.

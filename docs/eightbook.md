# 無限小說8book（測試版）0.1.1

Windows、Android 手機與平板使用相同來源，固定 ID `1827634454`。到「瀏覽 → 小說擴充套件」重新整理，將「無限小說8book（測試版）」更新至 **0.1.1**，再離開並重新開啟章節。本次不需要更換 App 或套件庫網址。

## 手機閱讀轉址修正

原先使用內建網頁載入閱讀頁，網頁的廣告及閱讀網域轉址也會執行，在手機可能被帶離指定章節。新版優先以一般 HTTP 取得 8book 的章節頁，確認作品 ID 與章節索引，解析頁面本身公開使用的正文檔網址，再取得完整正文。

只解析站方網址運算所需的數字、字串、索引和有限字串操作，不執行網頁的 JavaScript，不操作廣告、購物或錯誤回報功能。正文請求限制於 8book，並核對網址中的作品與章節 ID。

網站回應未註明編碼時，會修正 Dart HTTP 將 UTF-8 當成 latin1 顯示的情況。完整正文不再受站方閱讀頁的段落分頁限制，插圖也會保留。既有作品網址、章節網址及全書連續編號維持相容。

一般 HTTP 無法取得章節頁時，仍保留原本的 WebView 備援與閱讀網域核對；網站格式不符或回傳廣告／錯誤頁時，會顯示錯誤，不將其存成正文。

## 驗證

2026-11-01 核對站方 537 章目錄、兩篇正文與含 20 張圖片的插圖章節，均經來源的新讀取流程取得。自動測試涵蓋兩種公開網址運算、281 段長章節、UTF-8／latin1 相容、正文清理、錯誤作品或章節、陌生運算、HTTP 轉出站外、錯誤頁與限流，以及原本的備援流程。

未直接操作使用者的 Android 裝置，仍需在手機更新來源後確認。已下載的舊章節不會自動重抓；如有缺漏，請重新下載該章。

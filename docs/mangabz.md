# Mangabz

原創 Mangayomi JavaScript 漫畫來源，固定 ID `1827634458`，最低 App 版本 0.9.9。

在漫畫套件庫加入 `https://raw.githubusercontent.com/thomaslou0202/Mangayomi-Plugins/main/index.json`，重新整理擴充套件清單後安裝「Mangabz」。Windows 和 Android 使用同一份套件，不需要重新安裝 App。

## 支援範圍

- 熱門、最新更新與站方中文搜尋，支援翻頁。搜尋結果採用網站本身的比對方式。
- 作品資料、封面、介紹，以及包含隱藏項目的完整 HTML 章節目錄。
- 使用公開閱讀頁及其正常圖片介面，依頁數逐批取得圖片，附上章節 Referer。
- 章節名稱加上連續編號，讓 Mangayomi 的章節識別、名稱排序及閱讀器下一章使用一致順序。保留網站目錄順序，不重排站方本身混入的番外或重複話數。
- 圖片介面中的 packed JavaScript 只作字串資料解析，不執行其程式碼。缺少圖片、回到其他章節或圖片格式改變時會明確報錯。
- 網站驗證時可透過正常 WebView 讀取；仍需驗證時請自行在來源 WebView 完成。未提供登入、付費或驗證繞過功能。

## 備份相容性

接受原 Mangabz 的 `/{作品 ID}bz/` 與 `/m{章節 ID}/`，以及同站 HTTPS 完整網址。其他 App 的備份仍須轉換成 Mangayomi 原生備份，不能直接匯入。

遷移備份時，對應作品及章節 ID、補齊 HTTPS 網址，並內嵌已安裝的來源程式碼。閱讀進度、已讀、書籤與分類可以保留；既有本機下載檔案不會因轉換 metadata 自動搬移。私人備份不放在公開套件庫。

## 驗證

2026-10-24 以實際來源程式測試公開網站：

- 熱門第一頁、最新第二頁、中文搜尋第二頁均取得 12 筆作品，分頁可辨識。
- [海賊王作品頁](https://www.mangabz.com/139bz/)取得 978 個不重複章節網址，包含原頁面隱藏章節。網站標示的章數可能與 HTML 實際連結數不同，來源保留實際目錄。
- [第 1151 話](https://www.mangabz.com/m418076/)完整取得 13 張圖片；第一張圖片伺服器回傳 HTTP 206、JPEG 檔案標頭。
- 自動測試涵蓋搜尋編碼、兩種分頁、隱藏章節、App 章節去重及下一章排序、圖片分批、標頭合併、錯誤章節、圖片遺漏、網站驗證備援。

以上是實際 HTTP 圖片與解析器測試，沒有逐本驗證使用者書庫，也沒有代為還原或操作 App 資料庫。網站下架或原章節失效時，仍可能需要在 App 重新整理目錄。

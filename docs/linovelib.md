# 嗶哩輕小說（繁體）

版本 **0.1.5**，固定 ID `1827634460`，使用 [tw.linovelib.com](https://tw.linovelib.com/) 的繁體站，類型為「小說」。Windows 與 Android 手機／平板使用同一份來源，最低 Mangayomi 0.9.10；請使用本套件庫的 App **0.9.10+136 或更新版本**，讓 Windows 及平板的背景網頁也能以正確的手機尺寸排版。

已加入本套件庫的裝置，到「瀏覽 → 小說擴充套件」重新整理、顯示中文（zh），安裝「嗶哩輕小說（繁體）」即可，不需更換 App 或套件庫網址。

## 功能

- 熱門文庫與最新更新，均支援翻頁。
- 作品封面、作者、簡介、狀態與分卷目錄。
- 全書連續編號，保留各卷重複的序章、插圖、後記與章號，支援閱讀器下一章。
- 同一章有多頁時，連續取得同章分頁，取得完整正文後再交給閱讀器。
- 保留正文及插圖章節的圖片，配合本套件庫的插圖版 App 在正文內顯示。
- 搜尋可直接貼作品網址，例如 `https://tw.linovelib.com/novel/2013.html`，或輸入作品 ID `2013`。

## Windows 正文修正（0.1.5）

來源設定新增「正文讀取方式」，預設為「自動」：

- Windows 使用同站的 `www.linovelib.com` 官方桌面閱讀入口，取得完整正文後以隨來源內附的 OpenCC 字典轉為繁體，再交給 Mangayomi 小說閱讀器。
- Android 手機／平板沿用原本的繁體手機頁面；也可手動選擇閱讀入口。
- 作品、目錄、章節網址與書庫識別仍使用原繁體來源，閱讀進度及排序識別保持相容。
- 桌面回應核對作品 ID、章節 ID、頁碼、公開狀態與下一頁；沒有取得完整分頁就報錯，不把缺漏內容當成成功。

Windows 不必安裝瀏覽器輔助腳本，也不必更換系統 WebView2。到小說擴充套件更新至 0.1.5，離開並重新開啟 App 後再開章節。若要明確指定桌面入口，可在來源設定選「官方桌面入口（轉繁體）」。已下載的不完整舊內容需重新下載。

原繁體手機頁若有網站驗證或限制，仍按原本方式提示；桌面站遇到驗證、限流或受限章節也不會自動重試。

## 章節名稱（0.1.3）

卷名與章名開頭若包含完整作品書名，會移除這段重複書名，保留卷名、章名與全書連續編號。例如《無職轉生 ～到了異世界就拿出真本事～》：

```text
0001 | 第一卷 幼年期 插圖
0002 | 第一卷 幼年期 序章
0003 | 第一卷 幼年期 第一話「難道是：異世界」
```

0.1.3 將卷名開頭的一般整數卷號統一為中文，例如「1 幼年期」變為「第一卷 幼年期」、「17 青年期 阿斯拉王國篇（後）」變為「第十七卷 青年期 阿斯拉王國篇（後）」。支援全形數字及「第17卷」等寫法；原本的中文卷號、篇名和章名保持原樣，前面的全書排序編號仍使用阿拉伯數字。

支援書名的空白與全形／半形波浪號差異，僅清理標題開頭的完整書名，不刪除章名中正常出現的作品名稱。

更新方式：到「瀏覽 → 小說擴充套件」重新整理並更新至 0.1.5，回到已加入書庫的作品，重新整理作品目錄，再離開並重新開啟閱讀畫面。0.1.4 的正文修正請先安裝 App 136 或更新版本，再更新來源；無須刪除作品。章節網址與連續排序編號保持不變，App 可依原網址更新名稱並保留既有閱讀紀錄及書籤。

既有下載的儲存目錄包含舊章名；刷新目錄改名後，若需要離線閱讀，請重新下載相關章節。

## 關鍵字搜尋

網站目前使用 Google Programmable Search，來源沿用網站表單公開指定的搜尋引擎，會把輸入的關鍵字送到 `cse.google.com`。只保留繁體站的作品頁，排除廣告、其他網站與單一章節，並支援搜尋分頁。

結果取決於 Google 的收錄狀態，未收錄的作品不一定能以關鍵字找到；可改貼作品網址或 ID。遇到 Google 或站方驗證時，需手動完成驗證，來源不代解驗證，也不使用私人 API 金鑰或登入帳密。

## 讀取方式與限制

文庫、作品資料及目錄優先使用一般 HTTP。正文若帶有網頁腳本或版面樣式，會用手機尺寸的背景網頁完成網站正常排版，再擷取實際顯示的內容；不把原始 HTML 中隱藏的干擾段落當成正文。正文與分頁都核對作品 ID、章節 ID、頁碼和網域，避免跳到下一章或其他網站。來源只提供網站正常開放的內容，受限章節會提示到網站閱讀。

0.1.1 對暫時的網路中斷或 502／503／504 重試一次；正文回傳「內容加載失敗」時，只重試出錯的同章分頁，最多三次。仍失敗就保留錯誤供閱讀器重試，不回傳缺漏正文。網站驗證、404、429 與受限章節不自動重試。

站方目錄部分標題原本就含縮寫或替代字母，來源保留站方提供的名稱；章節正文使用閱讀頁的文字。搜尋和 WebView 備援會受裝置網路、網站驗證與 Google 服務可用性影響。

## 段落與載入修正（0.1.4）

- 等待正文腳本完成，再移除樣式隱藏的干擾段落；保留正常重複的對話，不以文字去重來猜段落順序。
- 正文仍含網站載入失敗提示、排版未完成或缺少章節資料時，不回傳部分章節。
- 一般網路／伺服器暫時錯誤沿用重試；背景網頁暫時失敗也會只重試出錯的同章分頁，最多三次，不重複先前成功的分頁。
- 網站驗證、轉址至其他網域、限流及受限章節不做自動重試。
- 若顯示 `LN-READER-VIEWPORT`，請先更新 App 到 0.9.10+136 或更新版本。舊的 Windows 背景網頁使用桌面尺寸，站方可能只顯示部分內容。

先安裝新版 App，再更新來源至 0.1.4；離開並重新開啟出問題的章節。若已下載該章的舊內容，請重新下載，套件不會自動改寫既有下載。

# 嗶哩輕小說（繁體）

版本 **0.1.0**，固定 ID `1827634460`，使用 [tw.linovelib.com](https://tw.linovelib.com/) 的繁體站，類型為「小說」。Windows 與 Android 手機／平板使用同一份來源，最低 Mangayomi 0.9.9。

已加入本套件庫的裝置，到「瀏覽 → 小說擴充套件」重新整理、顯示中文（zh），安裝「嗶哩輕小說（繁體）」即可，不需更換 App 或套件庫網址。

## 功能

- 熱門文庫與最新更新，均支援翻頁。
- 作品封面、作者、簡介、狀態與分卷目錄。
- 全書連續編號，保留各卷重複的序章、插圖、後記與章號，支援閱讀器下一章。
- 同一章有多頁時，連續取得同章分頁，取得完整正文後再交給閱讀器。
- 保留正文及插圖章節的圖片，配合本套件庫的插圖版 App 在正文內顯示。
- 搜尋可直接貼作品網址，例如 `https://tw.linovelib.com/novel/2013.html`，或輸入作品 ID `2013`。

## 關鍵字搜尋

網站目前使用 Google Programmable Search，來源沿用網站表單公開指定的搜尋引擎，會把輸入的關鍵字送到 `cse.google.com`。只保留繁體站的作品頁，排除廣告、其他網站與單一章節，並支援搜尋分頁。

結果取決於 Google 的收錄狀態，未收錄的作品不一定能以關鍵字找到；可改貼作品網址或 ID。遇到 Google 或站方驗證時，需手動完成驗證，來源不代解驗證，也不使用私人 API 金鑰或登入帳密。

## 讀取方式與限制

文庫、作品資料、目錄及正文優先使用一般 HTTP，不執行頁面廣告程式；必要時使用 App 內建網頁備援。正文與分頁都核對作品 ID、章節 ID、頁碼和網域，避免跳到下一章或其他網站。來源只提供網站正常開放的內容，受限章節會提示到網站閱讀。

站方目錄部分標題原本就含縮寫或替代字母，來源保留站方提供的名稱；章節正文使用閱讀頁的文字。搜尋和 WebView 備援會受裝置網路、網站驗證與 Google 服務可用性影響。

## 驗證範圍

2026-11-01 核對熱門與最新文庫、372 章分卷目錄、同一章的 3 頁正文及 13 張插圖，插圖伺服器亦回傳正常 JPEG。站方 Google 搜尋以「無職」核對第一、第二頁及作品連結；自動測試包含非同步搜尋分頁、章節排序、正文分頁、插圖、錯誤頁及網站驗證。

未直接操作使用者的手機或平板；安裝後請先測試一篇正文與插圖。無須清除書庫、匯入備份或重新安裝 App。

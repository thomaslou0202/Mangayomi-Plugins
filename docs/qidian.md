# 起點中文網（測試版）

來源版本 **0.1.0**，固定 ID `1827634459`，屬於「小說」。Windows 與 Android 手機／平板使用同一份套件，最低 Mangayomi 0.9.9。

在「瀏覽 → 小說擴充套件」重新整理，顯示中文（zh）來源後安裝「起點中文網（測試版）」。已加入本套件庫的裝置，不用更換清單網址或重新安裝 App。

## 提供的功能

- 使用[起點官方手機站](https://m.qidian.com/)；來源 WebView 也會開啟手機站。
- 首頁顯示網站熱門榜，榜單為單頁，未提供「最新」頁籤。
- 站方搜尋支援分頁；繁體關鍵字先轉為簡體，正文仍保留網站原文。
- 搜尋欄可直接輸入作品 ID、手機版或桌面版 `/book/作品ID/` 網址。
- 作品資料、封面、作者、簡介、分類與完整分卷目錄。
- 免費章節正文；在已簽約作品中，仍可閱讀免費章節與公開的作者後記。
- 收費章節保留於目錄並標示「VIP」，點擊會提示到官方網站或 App 閱讀。

本版不提供付費正文、購買、訂閱或帳密保存。遇到網站驗證時，請先在來源 WebView 手動完成，再重試。網站若提供受限字型或受限閱讀資料，來源會提示到官方閱讀。

## 目錄順序

維持官方目錄的分卷與章節順序，包括作品相關、序章及後記。全書加上 `0001｜` 連續序號，章節原名中的阿拉伯數字轉成全形，避免 App 將不同卷的同號章節判為重複。

章節清單選「按章節號」或「按名稱」，並讓 `0001` 排在最前面。閱讀器的下一章也以全書連續序號辨識。目錄宣告的章數多於實際取得時，會明確回報目錄不足，避免默默省略章節。

## 驗證範圍與維護

2026-10-30 以官方手機站核對首頁、搜尋前兩頁、作品資料、完整目錄、免費正文及付費提示。實際目錄樣本包含 6 章與 1,707 章的作品；未將網站小說正文或帳號資料提交到儲存庫。

自動測試包含分頁參數、繁簡搜尋、跨卷重複章號、完整章數、閱讀順序、免費／付費判斷、錯誤作品或章節、網站驗證備援與正文 HTML 清理。WebView 備援測試使用模擬網頁，實際裝置仍可能受網路、地區或網站驗證影響。

程式維護於 `templates/qidian.js`，以 `npm run build` 產生 `javascript/novel/src/zh/qidian.js` 及小說索引。搜尋繁簡轉換沿用儲存庫的 OpenCC TS 字典與 Apache-2.0 授權聲明。

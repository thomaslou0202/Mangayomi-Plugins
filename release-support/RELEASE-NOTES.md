# Mangayomi 繁體中文插圖版 0.9.10+134

- 修正起點中文網等作品在載入詳細資料或目錄時，出現「Cannot use the Ref … after it has been disposed」的問題。
- 作品載入任務會保留到完成；等待資料庫或來源回應期間，不會因沒有頁面訂閱而過早釋放。
- 離開作品頁後，已啟動的目錄載入仍可完成；重新載入或程式關閉後，過期回應不會開始寫入作品資料。
- 避免作品頁在首個畫面結束後，讀取已卸載的頁面狀態。
- 增加真實資料庫測試，涵蓋沒有訂閱者、離頁、任務失效、程式關閉與失敗後重試。
- 保留 133 版評論按鍵、小說正文插圖、繁體中文介面、書庫效能與背景同步。

## 安裝與更新

Windows：先關閉舊程式，再將 Mangayomi-windows.zip 解壓至原位置。本機固定使用 D:\Mangayomi\Windows\mangayomi.exe。

Android 手機／平板：下載 Mangayomi-android.apk 直接覆蓋更新，不必移除舊版。沿用既有套件名稱與簽章，保留書庫與設定。本機 APK 為 D:\Mangayomi\Android\Mangayomi.apk。

已安裝 0.9.10+132 或更新版本者，可從「更多 → 關於 → 檢查更新」取得本版。起點來源仍使用同一個小說套件庫，安裝 App 更新後重新開啟作品即可。

完整原始碼位於本倉庫 app-source 分支；Release tag 指向實際建置的 commit。兩平台通過分析、測試與建置，Android 完成簽章與裝置驗證後才發布，並提供 SHA256 校驗碼。

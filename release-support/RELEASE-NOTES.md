# Mangayomi 繁體中文插圖版 0.9.10+135

- 小說連續捲動模式接近章尾時預載下一章，章間顯示一小塊分隔，可直接往下接續閱讀。
- 跨過章節後更新標題、書籤與閱讀進度；預載本身不會記為已讀。正文快取限制為五章，舊章節仍可回捲重新載入。
- 下一章讀取失敗時保留已讀正文，在章末顯示重試按鈕。短章節及離開閱讀器後才收到的回應也有處理。
- 移除章節標題中重複的作品書名，保留章節名稱、卷名、編號及正文；舊的已下載章節也適用。
- 漫畫在章首繼續往前滑，可開啟上一章的最後一頁；支援左右翻頁及直向捲動。雙頁模式定位到包含最後一頁的書頁，捲動模式定位到該頁尾端。
- 修正漫畫雙頁模式開啟章節時重複轉換頁碼的問題，並保留原本手動選章的閱讀位置。
- 保留評論按鍵、小說正文插圖、繁體中文介面、書庫效能、背景同步與 134 版作品載入修正。

## 安裝與更新

Windows：先關閉舊程式，再將 Mangayomi-windows.zip 解壓至原位置。本機固定使用 D:\Mangayomi\Windows\mangayomi.exe。

Android 手機／平板：下載 Mangayomi-android.apk 直接覆蓋更新，不必移除舊版。沿用既有套件名稱與簽章，保留書庫與設定。本機 APK 為 D:\Mangayomi\Android\Mangayomi.apk。

已安裝 0.9.10+132 或更新版本者，可從「更多 → 關於 → 檢查更新」取得本版。小說請使用連續捲動模式。漫畫到章首後再往前滑動，即可開啟上一章末頁；第一章維持在章首。

嗶哩輕小說來源另請更新為 0.1.1：增加暫時網路／伺服器失敗重試，辨識網站「內容加載失敗」佔位文字，只重試出錯的同章分頁，不省略正文或分頁。來源更新不需重新加入套件庫。

完整原始碼位於本倉庫 app-source 分支；Release tag 指向實際建置的 commit。兩平台通過分析、閱讀器與既有功能測試及建置，Android 完成簽章與裝置驗證後才發布，並提供 SHA256 校驗碼。

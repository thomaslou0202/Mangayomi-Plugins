# Mangayomi 繁體中文插圖版 0.9.10+133

- 在作品詳情頁「推薦／相關作品」右邊新增「評論」按鍵，漫畫、小說與一般動畫詳情頁皆可使用。
- 用 App 內建網頁開啟來源網站，嘗試直接定位留言／評論區，保留網站本身的閱讀、分頁與登入操作。
- 支援包含漫畫櫃 `#Comment` 的常見留言區，以及稍後載入或顯示的留言元件。手動捲動或操作網頁後即停止延遲定位，不會一直把畫面拉回。
- 若網站沒有可辨識的留言區，保留完整作品網頁，可手動查看。本機作品不顯示網頁評論。
- 增加手機、平板與桌面按鍵排版測試；動畫按鍵較多時，在窄畫面自動換列。

## 安裝與更新

Windows：本機仍使用 `D:\Mangayomi\Windows\mangayomi.exe`。從 GitHub 下載時，先關閉舊程式，再解壓 `Mangayomi-windows.zip` 到固定資料夾。

Android 手機／平板：下載 `Mangayomi-android.apk` 直接覆蓋更新，無須移除舊版。本機安裝檔仍為 `D:\Mangayomi\Android\Mangayomi.apk`。

已安裝 0.9.10+132 者可從「更多 → 關於 → 檢查更新」取得本版。維持原套件名稱與簽章，保留書庫、來源設定、正文插圖、繁體中文及背景同步。

完整原始碼位於本倉庫 `app-source` 分支；此 Release tag 指向實際建置的 commit。兩平台通過分析與測試後才會發布，另提供 SHA256 校驗碼與上游授權。

# Mangayomi 繁體中文插圖版 0.9.10+136

- 背景網頁會沿用來源指定的 User-Agent，並為手機版來源使用手機尺寸，讓網頁 JavaScript 與版面得到一致的裝置環境。
- 修正 Windows 背景網頁以桌面尺寸載入嗶哩手機閱讀頁，造成章節正文不完整的問題。
- 搭配嗶哩輕小說來源 0.1.4：待網站完成手機版排版後，移除隱藏的干擾段落，僅取實際可見的正文，避免段落交錯。
- 網頁仍出現載入失敗或正文未完成時，不會把不完整內容當成正常章節保存。
- 桌面版來源與未指定 User-Agent 的來源保留原有尺寸。
- 保留 135 版小說跨章捲動、漫畫往前跨章至末頁、小說插圖、中文介面與背景同步。

## 安裝與更新

Windows：先關閉舊程式，再將 Mangayomi-windows.zip 解壓至原位置。本機固定使用 D:\Mangayomi\Windows\mangayomi.exe。

Android 手機／平板：下載 Mangayomi-android.apk 直接覆蓋更新，不必移除舊版。沿用既有套件名稱與簽章，保留書庫與設定。本機 APK 為 D:\Mangayomi\Android\Mangayomi.apk。

安裝本版後，到「瀏覽 → 小說擴充套件」更新嗶哩輕小說至 0.1.4，離開並重開出問題的章節。若已下載該章的舊內容，請重新下載；既有的不完整下載不會自動改寫。

完整原始碼位於 app-source 分支；Release tag 指向實際建置的 commit。兩平台通過分析、測試與建置，Android 完成簽章及裝置驗證後才發布。
